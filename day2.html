Tutor notes

These are called semantic tags: they describe the role of each part. Without CSS they look the same as a plain div, but they help browsers, search engines and screen readers understand the page.

Draw this layout on the board and ask learners to sketch a website they know and label its header, nav, main and footer.

How to explain it to students

Think of a house. The header is the front entrance, with the name of the house. The nav is the signs that tell you which rooms you can go to. The main is the living room, where most things happen. The footer is the back door, with information like opening hours. A web page is organised in the same way.

Each part has its own tag, so your code is tidy and easy to understand.

How to explain it to students

Here is how that structure looks in code. The header holds the site name and the nav. The nav holds the links. Then main holds the page content, and footer closes the page. See how tags sit inside each other, like boxes inside boxes? We indent the inner ones so we can see the nesting at a glance.

On their own, these tags don't change how the page looks. They just organise it. The looks come from CSS.

Classes: name tags for your elements

Bread
Cakes
Plain box
class="card" in HTML: no dot.card in CSS: with a dot

Tutor notes

A class lets you style some elements but not others, and reuse the style on as many elements as you like. Common slip: forgetting the dot in CSS or adding a dot in the HTML.

A div is a generic box: a container with no meaning of its own. It is how we group content for styling.

Class names: lowercase, no spaces, describe the purpose (card, hero, button).

How to explain it to students

Sometimes we want to style some things but not others. Not every box should look like a card. So we give the ones we want a class, which works like a name tag. In the HTML we write class equals card. In the CSS, we write a dot and then the same name: dot card. Now every element with that name tag gets the style.

Think of a school uniform. Everyone wearing the school badge gets the uniform look, and the others don't. Notice the plain box has no class, so it gets no style.

Check: How do you write the class in HTML, and how in CSS?

Tutor notes

A selector says which elements a rule applies to. IDs must be unique on a page, while classes can repeat. Classes are used far more often. Keep IDs for one-off elements such as the main hero.

The descendant selector (nav a) is powerful: it avoids adding classes to every link. Show it live: change nav a colour and watch only the nav links change.

How to explain it to students

You already know the element selector, like p. Here are four more. A class selector uses a dot, and styles everything with that class. An ID selector uses a hash, and styles one unique element. You can group selectors with commas, to style h1 and h2 the same way. And you can select things inside other things: nav a means only links inside the nav.

For most of today we'll use element selectors and classes.

The box model is one of the most important ideas in CSS. Every element, even a paragraph, is a rectangular box with these four layers. Use real objects: bring a small gift in a box, wrapped in bubble wrap and placed on a shelf, if you can.

In the browser, right-click an element and choose Inspect to see its box model in the developer tools. Show it live for a minute: it makes this concrete.

The picture is a simplified illustration.

How to explain it to students

Here's one of the most useful ideas in CSS. Every element on a web page is a box. Think of a gift. The gift itself is the content. The bubble wrap around it is the padding. The cardboard box is the border. And the space between your box and the next one on the shelf is the margin.

Padding is space inside, margin is space outside. If you remember only that, you've got it.

Part 3The box model

Shortcuts for spacing

padding: 10px;One value: all four sidestext
padding: 8px 24px;Two values: top and bottom, then left and righttext
padding: 4px 10px 18px 24px;Four values: top, right, bottom, left (clockwise)text

box

Tutor notes

Clockwise order for four values: top, right, bottom, left. A helpful memory aid is 'TRouBLe'. Two values are vertical then horizontal.

margin: 0 auto only centres a block that has a width or max-width set. Demonstrate with and without a width.

How to explain it to students

You don't have to write padding four times. With one value, it applies to all four sides. With two values, the first is top and bottom, and the second is left and right. With four, go clockwise: top, right, bottom, left, like the hands of a clock.

And here's a useful trick: margin zero auto centres a box on the page, as long as the box has a width. Zero is for top and bottom, and auto means 'share the left and right space equally'.

Look at the left. On a big screen, the text stretches all the way across and each line is very long. That's tiring to read. On the right, we put a max-width on the text and centre it with margin zero auto. Now the lines are shorter and the page looks tidy.

Max-width means 'be this wide at most'. On a small screen, the box can still shrink, which is what we want.

Tutor notes

Flexbox is applied to the parent (the container); it then arranges the children. The most common mistake is putting display: flex on the children instead of the parent.

Show it live: start with three stacked divs, add display: flex to their parent and watch them jump into a row. Then add gap.

How to explain it to students

By default, boxes stack on top of each other, like plates in a pile. Flexbox lets us put them side by side. It works like this: you give the parent, the container, display flex. The children inside it then line up in a row. Add gap to put space between them.

Remember: flex goes on the parent, not on the children. It's like telling a teacher to line up the whole class, not telling each student.

Check: On which element do you put display: flex?

Part 4Flexbox layout

Control the spacing and alignment

justify-content spreads items along the rowalign-items lines them up across the row

Tutor notes

Two directions: justify-content works along the main axis (the row), and align-items works across it. Have learners try each value on their own page.

space-between puts the first item at the start and the last at the end, with equal gaps between: perfect for a logo and menu in a header.

How to explain it to students

Once boxes are in a row, you can control how they are spread. Justify-content works along the row. Flex-start pushes them to the left, center puts them in the middle, and space-between pushes the first to the left and the last to the right, with equal space between.

Align-items works across the row, from top to bottom. It decides whether boxes line up at the top, in the middle, or at the bottom.

Check: Which value would you use to put a logo on the far left and a menu on the far right?

Tutor notes

border-radius rounds the corners; a bigger number gives rounder corners. box-shadow takes horizontal offset, vertical offset, blur and colour. rgba(0, 0, 0, 0.1) is black at 10% opacity: a soft shadow.

Let learners experiment: radius 0 vs 30px, shadow blur 5px vs 40px.

How to explain it to students

Two small properties can make a page look much more professional. Border-radius rounds the corners: a bigger number means rounder. Box-shadow adds a soft shadow under a box, so it seems to lift off the page. The numbers are: how far across, how far down, how blurry, and the colour. The colour here is black, but only ten percent strong, so the shadow is soft.

Try changing the numbers and see what you like.

Tutor notes

The :hover part is called a pseudo-class. It applies a rule only while the mouse is over the element. transition makes the change smooth instead of instant. On phones, there is no hover, so don't rely on it for essential information.

How to explain it to students

Websites feel alive when they react to your mouse. The colon hover part means 'when the mouse is over it'. Here, when you hover over a card it lifts up by six pixels, and when you hover over a nav link it changes colour. The transition line makes the movement smooth rather than a sudden jump.

It's a small touch that makes a site feel professional. Test it by moving your mouse over your cards.

In the head. It tells phones to use the real screen width.

Add flex-wrap: wrap; to your flex container. Cards drop to the next row when there is no room.

3. Fit your images

Tutor notes

Many people open websites on phones, so it is worth making this a habit from the start. Today is only a first step: full responsive design (media queries) comes later.

To test: make the browser window narrow, or use the device toolbar in the browser developer tools (right-click, Inspect). The cards in the exercise use flex: 1 1 200px, which means each card wants to be at least 200px wide and wraps to a new row when there isn't enough room.

How to explain it to students

Many people will open your website on a phone, so we should make sure it works on small screens. Three easy first steps. One: add this viewport line in the head, so phones use their real width. Two: add flex-wrap wrap to your flex container, so cards drop onto the next row when there's no space, like in the phone picture. Three: give images a max-width of one hundred percent, so no picture is wider than the screen.

There's more to learn about this later, but these three habits already help a lot.

Quick check

What is the box model?

Every element is a box made of content, padding, border and margin.

What is the difference between padding and margin?

Padding is space inside the border. Margin is space outside the border.

How do you select a class in CSS?

Put a dot before the name, for example .card

What does display: flex do?

It lays out the children of an element side by side in a row.

How do you centre a box that has a width?

margin: 0 auto;
