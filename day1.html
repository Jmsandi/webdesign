Tutor notes

A server is simply a computer that stores websites and sends them when asked. The browser (Chrome, Edge, Firefox, Safari) is the program that asks for pages and displays them.

Keep this high level. The point is that a web page is made of files, and those files are what we will write today.

How to explain it to students

Think of a restaurant. You sit down and order, that's your browser asking for a page. The kitchen prepares your food, that's the server. The waiter brings it to your table, and now you can eat. On the web, the 'food' is a set of files: HTML, CSS and pictures.

Your browser reads those files and builds the page you see. Today you will write those files yourself.

HTML turns tags into a page

HTML means HyperText Markup Language. You wrap content in tags to tell the browser what each piece is.

index.html

Tutor notes

HTML stands for HyperText Markup Language. 'Markup' means labelling content so the browser knows what it is. The browser reads the tags and decides how to show them.

Type this live in VS Code with Live Server open, so learners see the code change into a page.

How to explain it to students

HTML is the language we use to tell the browser what is on the page. We do it with tags. A tag is a word inside angle brackets. Look at the code on the left. The h1 tag says 'this is a big heading'. The p tag says 'this is a paragraph'.

On the right is what the browser shows. The tags themselves are invisible. The browser reads them and shows the heading big and the paragraph as normal text.

Part 3HTML

The anatomy of an HTML element

<p class="intro">Opening tagStarts the element. It can hold attributes.
Hello, world!ContentWhat people see on the page.
</p>Closing tagEnds the element. Note the slash.
Everything together is an element class="intro" is an attribute: extra information about the tag

Tutor notes

Most elements have an opening tag, content and a closing tag. The closing tag is the same as the opening tag with a slash. A forgotten closing tag is the most common beginner mistake.

Some elements have no content and no closing tag, for example the img tag. Mention this only if asked.

How to explain it to students

Let's take one element apart. At the start is the opening tag. In the middle is the content, the words people read. At the end is the closing tag, which looks like the opening tag but with a slash.

Inside the opening tag you can add attributes, like class here. An attribute gives the tag extra information. The whole thing together, from the opening tag to the closing tag, is called an element.

Check: How do you tell the closing tag from the opening tag?

Part 3HTML

Every page starts with this skeleton

<!DOCTYPE html><html lang="en"><head> <meta charset="UTF-8"> <title>My First Page</title></head><body> <h1>Hello, world!</h1></body></html>
<!DOCTYPE html>Tells the browser this is an HTML page.
<html>Wraps the whole page.
<head>Information about the page. Not shown on the page. The title appears on the browser tab.
<body>Everything people see.

Tutor notes

Have learners type this by hand, not copy it, so they get used to the tags. Afterwards show the shortcut: in an empty .html file, type ! and press Tab to generate the skeleton automatically.

Don't explain every line. Focus on head (about the page) and body (what people see). The meta charset line makes special characters display correctly, and lang declares the page language.

Walk the room and check that tags are closed and indentation looks tidy.

How to explain it to students

Every HTML page begins with the same skeleton. Let's go through it in simple pieces. The first line tells the browser this is an HTML page. Then the html tag wraps everything.

Inside it are two parts. The head holds information about the page: things like the title that appears on the browser tab. People don't see the head on the page. The body holds everything people actually see: headings, text, pictures.

Type it out now, line by line. Don't copy and paste. Typing it helps your fingers and your brain remember it.

Check: If I want to add a paragraph that people can read, does it go in the head or the body?

Part 4CSS

CSS: how to style a page

CSS means Cascading Style Sheets. A CSS rule says which part of the page to change, and how.

h1 { color: green;}
Selector: h1Which part of the page to style.
Property: colorWhat you want to change.
Value: greenWhat you want to change it to.
{ } and ;Curly brackets wrap the rule. A semicolon ends each line.

Tutor notes

The rule has three parts: selector, property, value. Missing semicolons and curly brackets are the most common CSS typos.

Keep to simple selectors (tag names like h1, p, body) today. Classes and ids come later.

Tell learners CSS is typed in a separate file (style.css), which we connect to the page on the next slide.

How to explain it to students

CSS is a list of style rules. Each rule has three parts. First, the selector, which says which part of the page you want to style. Here it's h1, so all the big headings. Second, the property, which says what you want to change. Here it's color. Third, the value, which says what to change it to. Here it's green.

The curly brackets wrap the rule, and each line ends with a semicolon. In plain English, this says: 'make every h1 green'.

Check: What would you change in this rule to make headings red?

Tutor notes

Normalise mistakes: every developer makes them all the time. Teach learners a calm routine: read the code slowly, compare with the example, then ask.

How to explain it to students

Everyone makes mistakes when coding, even experienced developers. Here are the five most common problems and what to check. Changes not showing up? Did you save, and did you refresh? Plain text in the browser? Check the file really ends in dot-html. Strange text after a tag? Check you closed every tag with a slash. CSS doing nothing? Check the link line in the head. One style not working? Check the colon, semicolon and brackets.

When something breaks, don't panic. Read your code slowly, one line at a time. Most bugs are small typos.

Quick check

What does HTML do?

What does CSS do?

It controls how the page looks: colours, fonts, sizes and alignment.

Which tag makes the biggest heading?

The h1 tag.

What is the difference between the head and the body?

The head holds information about the page. The body holds everything people see.

Which keys save your file in VS Code?

Ctrl+S (Cmd+S on a Mac).
